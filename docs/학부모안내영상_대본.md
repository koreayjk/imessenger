## 다시 만들려면

```bash
cd /tmp/claude-0/video
python3 makebgm.py                      # 배경음악
ffmpeg -y -i bgm/bright.wav -af "highpass=f=120,lowpass=f=7000" bgm/loop.wav
node record.js                          # 화면 녹화 (약 7분)
python3 detect.py                       # 싱크 표시 찾기
python3 build.py                        # 말·음악 얹어 완성
```

녹화할 때 오른쪽 아래 구석을 아주 잠깐 자홍색으로 물들여 두고(`mark.js`),
완성할 때 그 프레임을 찾아 말을 정확히 그 자리에 얹습니다. 시계로 잰 시각은
브라우저 녹화와 몇 초씩 어긋나기 때문입니다. 표시는 가장자리 1%를 잘라 없앱니다.
