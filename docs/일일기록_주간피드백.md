# 📋 일일기록 · 📬 주간 학부모 피드백

방과 후에 맡은 아이를 **매일 안에 기록**하고, **일주일에 한 번 학부모께** 드립니다.

> 매일 긴 보고를 보내면 정작 중요한 연락이 묻힙니다.
> 매일은 안에 남기고, 주 1회 골라서 드리는 것이 이 구조입니다.

---

## 설치 (한 번만)

```bash
cat db/일일기록_주간피드백_DB설치.sql | pbcopy
```
→ Supabase → **SQL Editor** → 붙여넣고 **Run**

끝에 정책 표와 함께 이 줄이 보여야 합니다:

```
익명 권한     | (없음)
```

`⚠️ 열려 있음` 이 나오면 `db/학부모_1_칸막이_DB설치.sql` 을 먼저 실행하세요.

## 📋 일일기록 — 매일 2~3분

**학사관리 → 📋 일일기록**

### 왜 다섯 영역인가

우리는 자체 커리큘럼을 가르치는 학원이 아니라, **미국 학교에 다녀온 아이를 방과 후에 맡습니다.**
그래서 "오늘 뭘 가르쳤나" 가 아니라 이것이 적을 거리입니다:

| 영역 | 적는 것 |
|---|---|
| 🏫 학교 | 학교에서 받은 과제·시험·제출기한 |
| 📘 과제 수행 | 혼자 한 것과 도움받은 것 |
| ⏱ 자기관리 | 스스로 시작했나 · 시간 관리 |
| 🤝 생활·인격 | 책임감 · 도움 요청하는 태도 |
| 🌱 오늘의 성장 | 어제보다 나아진 점 / 다음에 확인할 것 |

### 🔍 '막힌 곳' 이 이 기록의 핵심입니다

수학 문제를 틀려도 까닭이 다릅니다:

- **개념을 모름** → 개념을 다시 가르쳐야 합니다
- **영어를 못 읽음** → 수학이 아니라 지시문 읽기를 도와야 합니다
- **실수 / 시간 부족 / 집중**

**이걸 안 가르면 엉뚱한 걸 가르치게 됩니다.** 유학생 관리에서 가장 중요한 칸입니다.

### 글은 안 써도 됩니다

고르기만 해도 추세가 쌓입니다. **학생 한 명당 2~3분**이 목표입니다.
수업이 끝나기 전에 2~3분을 기록 시간으로 잡아 두세요 — 퇴근 직전에 몰아서 쓰면 관찰이 흐려집니다.

> 🔒 **교직원만 봅니다.** 학생도 학부모도 못 봅니다. 그래야 "아직 스스로 시작하지 못합니다" 를 솔직하게 적을 수 있습니다.

### 🗂 생기부로 보내기

기록 줄 오른쪽의 **🗂 생기부로** 를 누르면 창이 뜹니다.
**바로 집어넣지 않습니다** — 생기부는 공식 문서라 분류를 고르고 문장을 다듬어 보냅니다.
들어가는 곳은 이미 쓰시던 **관찰 누가기록(`observation_logs`)** 이라, 생기부 종합의견을 쓸 때 재료로 그대로 보입니다.

한 번 보낸 줄은 **🗂 생기부에 넣음** 으로 바뀌어 두 번 들어가지 않습니다.

## 📬 주간 피드백 — 주 1회

**학사관리 → 📬 주간 피드백**

학생과 주를 고르고 다섯 칸을 채웁니다. **빈 칸은 학부모 화면에 안 보입니다** — 쓸 말이 없으면 비워 두세요.

| 칸 | 쓸 것 |
|---|---|
| 👀 이번 주 한눈에 | 두세 줄 |
| 🌱 자란 것 | 점수가 아니라 **무엇이 달라졌는지** |
| 🔍 아직 도울 것 | 솔직하게. 숨기면 나중에 더 곤란합니다 |
| 📋 우리가 할 것 | 다음 주에 학원이 할 일 |
| 🏠 가정에서 | 집에서 도와주실 것 한 가지 |

### ⚠️ 저장만으로는 학부모에게 안 보입니다

- **💾 초안 저장** — 안에만 남습니다
- **📬 학부모에게 보내기** — 이걸 눌러야 보입니다

보낸 뒤에 고치면 학부모 화면도 바로 바뀝니다.

### 🔗 링크 보내기

보낸 뒤 **🔗 링크 보내기** 를 누르면:

- **복사** → 카톡·문자에 붙여넣기
- **💬 TCS 1:1 로 보내기** → 그 아이 학부모께 바로 전송 (앱 알림도 같이 갑니다)

링크는 `...#pf=<번호>` 꼴이고 **로그인해야 열립니다.** 아이 이야기라 아무나 열 수 없습니다.

> 연결된 학부모가 없으면 "연결된 학부모가 없어요" 라고 뜹니다.
> **관리자 → 멤버** 에서 아이와 학부모를 먼저 연결하세요.

## 👨‍👩‍👧 학부모가 보는 것

학부모가 로그인하면 **내 아이** 화면 맨 위에 **📬 주간 피드백** 이 있습니다.

- **주마다 쌓입니다** — 지난 주 것도 언제든 다시 볼 수 있어요
- 누르면 아이 이름·주차·선생님 이름이 찍힌 양식으로 열립니다
- 그 아래에 **글을 남길 수 있고, 선생님이 답글을 답니다**

댓글이 달리면 **상대에게 1:1 로 알림이 갑니다** — 글만 달아두면 아무도 안 봅니다.

## 누가 무엇을 보나

| | 일일기록 | 주간 피드백 | 댓글 |
|---|---|---|---|
| 교직원 | ✅ | ✅ (초안 포함) | ✅ |
| 학부모 | ❌ | ✅ **보낸 것만** | ✅ |
| 학생 본인 | ❌ | ❌ | ❌ |
| 로그인 안 한 사람 | ❌ | ❌ | ❌ |

**학생이 빠진 것은 일부러입니다.** 선생님이 솔직하게 쓰고, 학부모도 걱정을 편히 적을 수 있어야 합니다.
칭찬은 아이에게 따로 말해 주세요 — 그게 더 잘 전해집니다.

> 화면에서만 막은 것이 아니라 **서버(RLS)에서도 막혀 있습니다.** 주소를 알아도 안 열립니다.

## 운영하실 때

| 때 | 할 일 |
|---|---|
| 수업 끝나기 2~3분 전 | 학생별 일일기록 (고르기 + 한두 줄) |
| 주 1회 | 일일기록을 훑어 **성장 하나 · 보완 하나** 를 골라 주간 피드백 작성 → 보내기 |
| 급한 일 | 주간 피드백을 기다리지 말고 **그날 1:1 로** 연락 |
| 학기 중 | 생기부에 넣을 만한 줄은 그때그때 **🗂 생기부로** |

기록이 개인의 기억이나 성실함에만 기대지 않게 하는 것이 목적입니다.
원장은 기록을 검사하지 마시고, **도움이 필요한 학생과 강사를 찾는 데** 쓰세요.
