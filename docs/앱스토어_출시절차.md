## ⛔ 먼저 — 이것 하나를 안 하면 무조건 반려됩니다

**새로 가입하면 `승인 대기 중` 에서 멈춥니다.** 심사자가 직접 가입하면
앱을 하나도 못 보고, 애플은 "앱을 볼 수 없다"(지침 2.1)로 되돌려 보냅니다.

그래서 **미리 만들어 둔 데모 계정**을 주고, **가입하지 말라고** 적어야 합니다.

### 데모 계정 만들기

1. 평소처럼 가입합니다 — 예: `appreview@imusa.org`
2. **관리자로 들어가 그 계정을 승인합니다** (관리 → 멤버 → 승인)
3. 역할은 **교사** 로 둡니다
   - 학생으로 두면 생기부·관리 화면을 못 봐서 "기능이 안 보인다" 는 말을 듣습니다
   - 총관리자로 두면 심사자가 실수로 진짜 자료를 건드릴 수 있습니다
4. 로그아웃하고 **그 계정으로 직접 들어가 봅니다** — 승인 대기가 뜨면 ②를 다시

## 1. 올리기 전 맞춰 둘 것

```bash
cd ~/imessenger
git pull
npm i          # 플러그인이 바뀌었을 수 있습니다
npm run ios
```

Xcode 가 열리면 **Archive 하기 전에** 반드시:

```bash
md5 index.html ios/App/App/public/index.html
```

**두 값이 같아야 합니다.** 다르면 앱 안에 옛 화면이 담깁니다.
(이것 때문에 "고쳤는데 왜 그대로지?" 를 여러 번 겪었습니다)

### 판 번호

Xcode → App → General

- **Version** `1.0` — 사람이 보는 번호
- **Build** `1` — 올릴 때마다 **반드시 1씩 올립니다.** 같은 번호로는
  두 번 못 올립니다. 반려돼서 다시 올릴 때도 올려야 합니다.

## 2. Archive 하고 올리기

1. Xcode 위쪽 기기 고르는 곳을 **Any iOS Device (arm64)** 로
   (시뮬레이터로는 Archive 가 안 됩니다)
2. **Product → Archive**
3. Organizer 가 뜨면 **Distribute App → App Store Connect → Upload**
4. 서명은 **Automatically manage signing** 으로 둡니다

올라가면 App Store Connect 의 TestFlight 에 10~30분 뒤 나타납니다.
