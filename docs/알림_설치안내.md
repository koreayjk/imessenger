# 🔔 알림 설치 안내 (2단계 — 앱을 닫아도 오는 알림)

1단계(앱이 켜져 있을 때)는 아무 설치 없이 이미 됩니다.
여기는 **앱을 닫아 두어도** 알림이 오게 하는 설정입니다.

| 기기 | 2단계로 되나 |
|---|---|
| 컴퓨터 브라우저 (크롬·엣지·파이어폭스·사파리) | ✅ |
| 안드로이드 — 브라우저 | ✅ |
| 안드로이드 — **앱** | ✅ **단, AAB 를 다시 빌드해 올려야 합니다** |
| 아이폰 — 사파리에서 '홈 화면에 추가' 한 경우 | ✅ (iOS 16.4 이상) |
| 아이폰 — **앱(App Store)** | ❌ **애플 APNs 가 따로 필요합니다 (3단계)** |

---

## 1. DB 표 만들기

Supabase → SQL Editor:

```
db/알림_푸시_DB설치.sql
```

---

## 2. 함수 올리기

터미널에서 (주석 `#` 을 같이 치지 마세요 — zsh 가 패키지 이름으로 읽습니다):

```
cd ~/imessenger
supabase functions deploy push-notify
```

---

## 3. 비밀값 세 개 넣기

```
supabase secrets set VAPID_PUBLIC=BMBU-XhqjL3n1yVOf_V097vf0DOKbvCTXDmuBjVNhWmM-o0h1oFqBnhdSHHbaE3lS6G0AUAcCfmpR49A3TelmB4
supabase secrets set VAPID_PRIVATE=여기에_비밀키
supabase secrets set VAPID_SUBJECT=mailto:imamerica2414@gmail.com
```

> 🔐 **`VAPID_PRIVATE` 는 대화창으로 따로 드렸습니다.**
> 이 파일에도, 코드 어디에도 적지 마세요. 공개 저장소라 올라가면
> 남이 우리 이름으로 TCS 사용자들에게 알림을 보낼 수 있습니다.
> 공개키(`VAPID_PUBLIC`)는 공개돼도 괜찮습니다 — 이미 `index.html` 에
> 들어 있습니다.

Supabase 대시보드에서 넣으셔도 됩니다:
**Project Settings → Edge Functions → Secrets**

---

## 4. 써 보기

1. TCS 를 열고 **내 프로필 → 🔔 알림**
2. **[알림 켜기]** → 브라우저가 물어보면 허용
3. 그 아래 **「앱을 닫아도 알림 받기」 → [켜기]**
4. **탭을 완전히 닫고**, 다른 분께 그 방에 메시지를 보내 달라고 하세요

> 기기마다 한 번씩 켜야 합니다. 노트북과 휴대폰은 따로입니다.

---

## 5. 안드로이드 앱에 반영하려면

지금 올라가 있는 앱은 알림이 꺼진 채로 빌드돼 있습니다
(`twa-manifest.json` 의 `enableNotifications` 가 `false` 였습니다).
방금 `true` 로 바꿔 두었으니, **AAB 를 다시 만들어 올리셔야** 합니다.

1. PWABuilder 에서 다시 패키지를 받거나, Bubblewrap 을 쓰신다면
   `bubblewrap update && bubblewrap build`
2. **버전을 올리세요** — Play 는 같은 버전 번호를 두 번 안 받습니다
   (`appVersionName` 1.0.0 → 1.0.1, 버전 코드 1 → 2)
3. Play Console → 프로덕션 → 새 버전 → 올리고 검토 요청

⚠️ **서명 키는 처음 것 그대로 써야 합니다.** 다른 키로 서명하면
업데이트가 아니라 남의 앱이 되어 거부됩니다.

---

## 6. 안 되면 여기부터 보세요

| 증상 | 볼 곳 |
|---|---|
| 「알림 켜기」를 눌러도 아무 일이 없다 | 브라우저가 이미 막아 둔 경우입니다. 주소창 왼쪽 자물쇠 → 알림 → 허용 |
| 켰는데 안 온다 | Supabase → Edge Functions → `push-notify` → Logs. `VAPID 키가 없습니다` 면 3번을 안 한 것입니다 |
| 앱을 켜 두면 오는데 닫으면 안 온다 | 「앱을 닫아도 알림 받기」를 안 켠 것입니다 (2번과 3번은 따로입니다) |
| 아이폰 앱에서 안 온다 | 정상입니다. 3단계(APNs)가 필요합니다 |
| 껐는데 계속 온다 | 다른 기기에서 켜 둔 것입니다. 그 기기에서 끄세요 |

## 7. 어떻게 도는가 (나중에 손볼 때를 위해)

```
보내는 사람 ─ 메시지 저장
            └→ push-notify 함수 호출 (메시지 번호만 넘김)
                 │
                 ├ 서버가 다시 확인: 그 메시지가 진짜인가,
                 │                   부른 사람이 정말 쓴 사람인가
                 ├ 그 방 사람들을 찾는다 (쓴 사람 제외, 차단한 사람 제외)
                 ├ 기기마다의 설정을 본다 (끈 방·나를 부른 것만·미리보기)
                 └→ 각 기기로 웹푸시
                      └ 브라우저가 sw.js 를 깨워 알림을 띄운다
```

제목과 내용은 **클라이언트가 보내 준 것을 쓰지 않습니다.** 서버가
메시지를 직접 읽습니다. 안 그러면 아무나 남의 이름으로 알림을
뿌릴 수 있습니다.

받지 않는 기기(브라우저를 지웠거나 끈 경우)는 404·410 이 돌아오고,
그 줄은 자동으로 치워집니다.
