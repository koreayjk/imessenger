# 📞 아이폰 전화 화면 (CallKit)

전화가 오면 **잠금화면에 전체화면 전화 화면**이 뜨고, 시스템 벨소리로
계속 울리고, 잠금을 풀지 않고 받을 수 있습니다.

---

## 일을 어떻게 나눴나 — 여기가 제일 중요합니다

**CallKit 은 '벨 울리고 받는 화면' 까지만** 맡습니다.
받고 나서 오가는 소리는 지금까지처럼 **웹뷰(WebRTC)** 가 맡습니다.

왜 이렇게 나눴냐면, CallKit 은 앱이 소리를 직접 쥐고 있다고 봅니다.
그런데 우리 소리는 웹뷰 안에서 납니다. 둘이 서로 소리를 가져가려고
다투면 **'받았는데 안 들리는'** 일이 생깁니다 — 그 증상으로 이미 한 번
크게 고생했습니다.

그래서 `didActivate audioSession` 을 **일부러 비워 두었습니다.**
비어 있는 게 맞습니다. 채우지 마세요.

---

## 켜는 순서

### 1. 데이터베이스 (한 번만)

Supabase → SQL Editor → `db/전화화면_CallKit_DB설치.sql`

애플은 **알림용 표**와 **전화용 표(VoIP)** 를 따로 줍니다. 한 줄에 같이
둘 수 없어서 `kind = 'ios_voip'` 로 한 줄 더 받는데, 지금 제약이 그걸
막고 있습니다. **안 넓히면 표가 조용히 저장되지 않고 전화 화면이 영영
안 뜹니다** (오류는 콘솔에만 남습니다).

### 2. 서버 (Edge Function)

```bash
supabase functions deploy push-notify
```

열쇠는 **지금 쓰는 APNs `.p8` 그대로** 입니다. 애플에 따로 받을 것이
없습니다. 보낼 때 주소 뒤에 `.voip` 를 붙이고 종류를 `voip` 로 합니다.

### 3. 아이폰 앱

```bash
npm run ios
```

Xcode 가 열리면 **Signing & Capabilities** 에서 확인하세요:

| | |
|---|---|
| **Background Modes** | `Voice over IP` 가 켜져 있어야 합니다 (Info.plist 에 넣어 뒀으니 보일 겁니다) |
| **Push Notifications** | 이미 켜져 있습니다 |

새로 들어간 파일 둘이 **프로젝트에 담겼는지** 보세요 —
`TCSCallKit.swift` · `CallKitPlugin.swift` 가 왼쪽 목록에 보이고,
**Target Membership 에 App 이 체크**되어 있어야 합니다.
(`npx cap sync ios` 가 보통 알아서 담지만, 가끔 빠집니다)

그리고 Archive.

## 확인하는 법

실제 아이폰 **두 대**가 필요합니다. 시뮬레이터로는 안 됩니다
(VoIP 푸시가 안 옵니다).

1. 두 기기에 새 앱을 깔고 **각각 한 번씩 엽니다** — 그때 VoIP 표가 저장됩니다
2. 한쪽 아이폰을 **완전히 끄고(앱 종료) 잠급니다**
3. 다른 쪽에서 전화를 겁니다
4. 잠긴 아이폰에 **전체화면 전화 화면**이 뜨고 계속 울려야 합니다
5. 잠금화면에서 바로 **받기** → 앱이 올라오고 소리가 오가야 합니다

표가 저장됐는지는 이렇게 봅니다:

```sql
select kind, left(endpoint, 12) || '…' as "표", enabled
  from public.push_subscriptions
 where member_id = '<그 사람 id>';
```

`ios` 와 `ios_voip` **두 줄**이 보여야 합니다.

## 안 되면 어디를 보나

| 모습 | 거의 이것입니다 |
|---|---|
| 전화 화면이 아예 안 뜬다 | `ios_voip` 줄이 없습니다 → ① SQL 을 안 돌렸거나 ② 앱을 한 번도 안 열었습니다 |
| 앱이 켜져 있을 때만 뜬다 | Background Modes 의 `Voice over IP` 가 꺼져 있습니다 |
| 뜨는데 소리가 안 난다 | 전화 쪽이 아니라 마이크 쪽입니다 — 통화 화면 아래 진단 줄을 보세요 |
| 두 번 울린다 | 서버가 보통 알림까지 같이 보낸 것입니다 (`hasVoip` 가 안 걸렸습니다) |

---

## ⚠️ 절대 하면 안 되는 것

VoIP 푸시를 받으면 **그 자리에서 반드시** `reportNewIncomingCall` 을
불러야 합니다. 안 부르면 iOS 가 앱을 죽이고, 몇 번 반복되면
**VoIP 푸시를 아예 안 보내 줍니다.** 되돌릴 길이 없습니다.

그래서:
- "혹시 모르니 미리 보내두기" 같은 VoIP 푸시는 **절대 보내지 마세요.**
  진짜로 전화가 울릴 때만 보냅니다 (서버가 그렇게 돼 있습니다)
- `didReceiveIncomingPush` 안에서 무엇을 고치든, **전화를 알리는 줄은
  건드리지 마세요.** 시험(`test/전화화면점검.js`)이 그걸 지킵니다

안드로이드에는 CallKit 이 없습니다. 같은 모습을 내려면 전체화면
알림(full-screen intent)으로 따로 만들어야 합니다 — 아직 안 했습니다.
안드로이드는 지금처럼 알림으로 옵니다.
