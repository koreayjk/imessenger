# 공동체 이동 (무빙)

학생이나 사역자가 다른 공동체로, 또는 해외(IM USA · IMOHP)로 옮길 때 쓰는 길입니다.

---

## 어디서 하나

**관리 ▸ 멤버** → 맨 위 **「🔎 사람 찾기 · 공동체 이동」** 카드
→ 이름이나 이메일을 **두 글자 이상** 넣고 찾기 → **🏛️ 공동체 이동** → 옮길 공동체 선택

공동체를 이미 아신다면 **🏛️ 공동체 ▸ 멤버 보기** 에서도 같은 일을 할 수 있습니다.

### 누가 할 수 있나

| | 할 수 있는 이동 |
|---|---|
| **총관리자** | 어디로든. 부총관리자를 옮기는 것도 총관리자만. |
| **부총관리자** | **자기 묶음 안에서만.** 리뉴젠 공동체 ↔ 리뉴젠 공동체 는 되고, 국내 ↔ 해외 는 안 됩니다. |
| 공동체 관리자 아래 | 할 수 없습니다. |

화면과 서버가 같은 줄을 긋습니다. 화면에서 단추가 안 보이는 것과, 서버가 막는 것이 따로 놀지 않습니다.

---

## 누르기 전에 확인창이 보여주는 것

확인창은 **아무것도 바꾸지 않은 상태**에서 먼저 뜹니다. 네 덩이입니다.

**1. 자동으로 떨어지는 것**
반 · 담임 · 담당교사 배정 · 채팅방 참여 · 개인 시간표. 전부 이전 공동체 것이라 끊깁니다.

**2. 💰 자동 정산되는 잔액**
```
💰 잔액을 자동으로 정산합니다 (프로토스 에서 빼고 어웨이크닝 에 넣습니다):
· 예치금 ₩189,540 → 어웨이크닝 로
· 용돈 -₩24,900 → 어웨이크닝 로
```
이전 공동체에 「공동체 이동 정산」 출금을 적어 **잔액을 0으로** 만들고,
새 공동체에 **같은 금액 · 같은 통화**로 입금을 적습니다. 양쪽에 기록이 남습니다.

> **환율은 건드리지 않습니다.** ₩ 잔액은 ₩ 그대로 넘어갑니다.
> 달러 공동체로 옮겼다면 **환산은 받는 공동체 행정담당자가 직접** 하세요
> (₩ 출금 한 줄 + $ 입금 한 줄). 자동으로 환율을 곱하면 틀린 금액이 조용히 남습니다.

마이너스 잔액(쓴 돈이 더 많은 경우)도 같은 방식으로 따라갑니다.

**3. 📖 새 공동체가 읽을 수 있게 되는 기록**
```
📖 어웨이크닝 선생님이 읽을 수 있게 되는 기록 (옮겨지지는 않고, 읽기만):
· 생활기록부 9건
· 출결 120건
```
- **생활기록부** (성적 · 모의고사 포함) · **출결** · **독서 기록** · **독후감 · 활동후기**
- **읽기만** 됩니다. 고치거나 지우는 것은 여전히 그 기록을 가진 공동체만 합니다.
- 기록은 **이전 공동체에 그대로 남습니다.** 옮겨 가는 것이 아니라, 새 공동체가 들여다볼 수 있게 되는 것입니다.
- 학생 **본인**은 어디에 있든 자기 기록을 계속 봅니다.

**4. 🔒 이전 공동체에만 남는 것**
```
🔒 프로토스 에만 남는 기록 (어웨이크닝 에서 안 보입니다):
· 상담 기록 2건
· 채팅 메시지 40건
```
**상담 기록 · 보건 기록 · 관찰 기록 · 노트 · 기도제목 · 채팅 메시지**는 열지 않습니다.
아이와 부모가 「여기서만 보는 것」으로 알고 적은 내용이기 때문입니다.
새 공동체에 꼭 전해야 한다면, 이전 공동체가 **보고 판단해서** 따로 건네주세요.

## 권하는 순서

1. **필요하면 이전 공동체에서 증명서를 먼저 뽑아** 자료실에 올려 둡니다.
   증명서는 발급한 공동체에 남습니다 — 재발급은 이전 공동체가 합니다.
2. **공동체 이동**을 실행합니다. 확인창 내용을 한 번 캡처해 두면 나중에 찾기 좋습니다.
3. **새 공동체에서** 반 · 담임 · 채팅방을 다시 넣습니다.
4. 통화가 다른 공동체라면 **환산**을 손으로 처리합니다.

---

## 되돌리려면

반대 방향으로 한 번 더 옮기면 됩니다. 다만 **자동으로 되돌아가지는 않습니다** —
정산 기록이 양쪽에 또 한 줄씩 쌓이고, 반 · 담임 · 채팅방은 다시 넣어야 합니다.

이동 이력은 `member_moves` 에 남습니다. 이력이 있어야 새 공동체가 이전 기록을 읽을 수 있으므로,
**이력을 지우면 읽기 권한도 같이 닫힙니다.**
