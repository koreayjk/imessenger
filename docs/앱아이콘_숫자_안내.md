# 🔴 앱 아이콘의 빨간 숫자 (배지)

> "알림설정해서 문자오면 잘뜨는데 어플아이콘에 숫자는 안뜨나?"

**안 떴습니다.** 알림 내용만 보내고 **숫자 칸(`badge`)을 아예 비워서**
보내고 있었습니다. 애플은 그 칸에 적힌 수를 그대로 아이콘에 붙이고,
안 적어 보내면 아무것도 안 붙입니다.

---

## 고친 것

**받는 사람마다 "지금 몇 개 안 읽었는지"를 서버가 세서 같이 보냅니다.**
화면에서 세던 것과 같은 셈입니다:

> 내가 들어가 있는 방들에서 · 내가 쓰지 않았고 · 가려지지 않았고 ·
> 내가 그 방을 마지막으로 읽은 시각보다 나중에 온 글

한 번도 읽은 적 없는 방은 최근 45일치만 셉니다(화면과 같은 기준).
**👁 지켜보는 방은 안 셉니다** — 총관리자님 아이콘이 늘 세 자리가 되면
숫자가 아무 뜻이 없어집니다.

읽으면 앱에서도 같이 맞춥니다. 서버는 *알림을 보낼 때만* 숫자를 고칠 수
있어서, 다 읽고 나서 새 글이 안 오면 숫자가 그대로 남기 때문입니다.

## 🖥 설치

```bash
cd ~/imessenger && git pull origin main && cat db/앱아이콘_숫자_DB설치.sql | pbcopy
```
→ 🗄 Supabase **SQL Editor** 붙여넣고 **Run**

```bash
npx supabase functions deploy push-notify
```

> 이 두 가지를 해야 숫자가 뜹니다. SQL 을 안 깔아도 **알림 자체는 그대로**
> 옵니다 — 숫자만 안 붙습니다.

## 어디서 얼마나 되나

| | 숫자가 뜨나 | 다 읽으면 저절로 지워지나 |
|---|---|---|
| **아이폰 앱** | ✅ | ✅ 읽는 즉시 (플러그인 설치됨) |
| 홈 화면에 추가한 아이폰 (사파리) | ✅ | ✅ |
| 안드로이드 설치형 | ✅ | ✅ |
| 그냥 브라우저 | — | — |

### 아이폰 앱의 숫자 지우기

`@capawesome/capacitor-badge` 를 넣었습니다. 읽는 즉시 지워집니다.

- 알림을 켤 때 **배지 권한도 같이** 받습니다. 알림 권한을 방금 받은
  직후라 묻는 창이 또 뜨지는 않습니다. 이미 허락돼 있으면 안 묻습니다
- **앱으로 돌아올 때마다** 안읽음을 다시 세어 숫자를 맞춥니다
- 아이폰에서는 숫자를 0 으로 만들면 **알림 목록도 같이 비워집니다**
  (플러그인이 아니라 애플이 그렇게 정해둔 동작입니다)

플러그인이 없어도 숫자는 뜹니다 — 코드가 그 경우를 보고 조용히
넘어가고, 서버가 보낸 숫자는 그대로 붙습니다.

---

## 왜 웹에는 `badge` 가 아니라 `count` 로 보내나

브라우저 알림에서 `badge` 는 **"알림 옆에 붙는 작은 단색 그림"** 을
뜻합니다. 거기에 숫자를 넣으면 알림 아이콘이 깨집니다. 아이콘에 붙는
숫자는 `setAppBadge` 라는 다른 길입니다. 이름이 같아서 헷갈리는
자리라, 보낼 때부터 `count` 로 갈라 두었습니다.

## 왜 '0' 을 안 보내나

세는 데 실패하면 `badge` 칸을 **아예 안 적습니다.** `0` 을 적으면 애플이
"다 읽었다"로 알아듣고 **있던 숫자까지 지웁니다.** 모르는 것과 0 은
다릅니다.
