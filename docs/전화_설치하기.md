# 📞 전화 넣기 — 한 번만 해두면 됩니다

TCS 안에서 **소리 통화**를 켭니다. 선생님이 학생에게, 학생이 선생님에게 바로 전화할 수 있어요.

- 소리는 **두 기기가 직접** 주고받습니다. 서버를 지나가지 않고 **녹음도 하지 않습니다.**
- 남는 것은 **누가·누구에게·언제·몇 분**입니다. 내용은 없습니다.
- **학생끼리는 걸 수 없습니다** — 1:1 채팅과 같은 규칙입니다.
- 한 통화는 기본 **10분**이면 저절로 끊어집니다 (관리자가 바꿀 수 있어요).

할 일은 셋입니다. **1번만 하면 전화는 됩니다.** 2·3번은 학교 와이파이에서도 되게 하는 것입니다.

---

## 1단계 — 표를 만듭니다 (꼭 해야 함)

Supabase → **SQL Editor** → 아래를 붙여넣고 **Run**.

```bash
cat db/통화_DB설치.sql | pbcopy
```

끝에 이런 표가 나오면 된 것입니다.

```
     정책     |  대상
--------------+--------
 calls_insert | INSERT
 calls_select | SELECT
 calls_update | UPDATE

     설정      | 값
---------------+----
 통화 제한(분) | 10
```

> 먼저 `db/전체잠그기_RLS.sql` 과 `db/신고차단_DB설치.sql` 이 깔려 있어야 합니다.
> 두 번 돌려도 안전합니다.

이것만 하면 **집·휴대폰 통신망에서는 전화가 됩니다.**

---

## 2단계 — 중계(TURN)를 켭니다 (학교 와이파이에서 되게)

학교·회사 와이파이는 방화벽이 세서 기기끼리 바로 못 붙을 때가 있습니다.
그때 소리를 **중계**해 주는 것이 TURN 입니다. 재 보면 **전체 통화의 20~25%** 가 이게 있어야 붙습니다.
안 켜도 전화 기능은 돌아갑니다 — 다만 학교에서 "벨은 울리는데 소리가 안 들려요" 가 생깁니다.

Cloudflare 가 **한 달 1,000GB까지 공짜**로 줍니다. 소리만 쓰는 통화는 1분에 1MB 도 안 되니
(넉넉히 1MB 로 잡아도) **한 달에 1만 시간이 넘게** 중계해도 공짜 범위입니다.
게다가 중계를 타는 통화는 전체의 20~25% 뿐입니다. 넘으면 1GB 당 $0.05 입니다.

1. [dash.cloudflare.com](https://dash.cloudflare.com) 에 가입(무료)합니다.
2. 왼쪽에서 **Realtime**(옛 이름 Calls) → **TURN** → **Create** 를 누릅니다.
3. 두 가지가 나옵니다. **그 창을 닫으면 토큰은 다시 볼 수 없습니다.** 먼저 적어 두세요.
   - **Key ID** — 짧은 글자·숫자
   - **API Token** — 긴 글자·숫자

4. 터미널에서 Supabase 비밀값에 넣습니다. (`<...>` 안에 방금 받은 값)

```bash
supabase secrets set CF_TURN_KEY_ID=<여기에 Key ID> \
                     CF_TURN_API_TOKEN=<여기에 API Token> \
                     --project-ref bbfvnmlrdtzmcwfadjqw
```

> 🔐 **이 두 값을 git 에 올리지 마세요.** 공개 저장소입니다.
> 코드 어디에도, 이 문서에도 적지 마세요. Supabase 비밀값에만 둡니다.
> 앱(브라우저)에는 내려가지 않습니다 — 서버가 통화마다 **1시간만 사는 자격**을 만들어 건네줍니다.

---

## 3단계 — 자격을 만들어 주는 함수를 올립니다

```bash
supabase functions deploy turn-credentials --project-ref bbfvnmlrdtzmcwfadjqw
```

이미 있는 `push-notify` 도 전화 알림을 쏠 수 있게 바뀌었으니 같이 올립니다.

```bash
supabase functions deploy push-notify --project-ref bbfvnmlrdtzmcwfadjqw
```

## 되는지 보기

1. 브라우저 두 개(또는 휴대폰 + 노트북)에서 **다른 사람으로** 로그인합니다.
2. 1:1 대화를 열면 위쪽에 **📞** 가 보입니다. 사람 이름을 눌러도 **📞 전화 걸기** 가 있어요.
3. 걸면 상대 화면에 **받기 / 거절** 이 뜹니다.
4. 받으면 시간이 돌아갑니다. 남은 시간도 보입니다.

**중계가 켜졌는지** 보려면 브라우저 개발자도구 → Console 을 봅니다.

| 보이는 글 | 뜻 |
|---|---|
| (아무 말 없음) | 중계까지 잘 켜졌습니다 |
| `📞 중계 꺼짐: CF_TURN_KEY_ID/CF_TURN_API_TOKEN 이 없습니다` | 2단계를 아직 안 했습니다 (집에서는 그래도 됩니다) |
| `📞 중계 꺼짐: Cloudflare 401 …` | 토큰이 틀렸습니다. 2단계를 다시 하세요 |
| `📞 중계 없이 갑니다` | 3단계(함수 올리기)를 아직 안 했습니다 |

## 관리자가 바꿀 수 있는 것

**관리자 → ⚙️ 공동체 설정** 에 두 가지가 있습니다.

- **📞 전화 — 한 통화의 시간 제한**
  제한 없음 / 5 / 10 / 15 / 20 / 30 / 45 / 60분. 끊기기 **30초 전**에 양쪽에 알려줍니다.
  수업에 방해되지 않게, 그리고 중계 데이터를 아끼려고 **10분**을 권합니다.
- **📞 전화 기록**
  최근 40통. 누가·누구에게·언제·몇 분. **지우는 단추가 없습니다** —
  지울 수 있으면 기록이 아닙니다. 데이터베이스에서도 `delete` 권한을 아예 주지 않았습니다.

## 아이폰 앱

`npm run ios` 로 다시 빌드해야 전화가 들어갑니다. 마이크 권한 설명은
`ios/App/App/Info.plist` 의 `NSMicrophoneUsageDescription` 에 이미 넣어 두었습니다.

> ⚠️ **시뮬레이터에는 마이크가 없습니다.** 반드시 실제 아이폰에 올려서 걸어 보세요.
> 처음 걸 때 "마이크를 사용하도록 허용하겠습니까?" 가 한 번 뜹니다.

> **아이폰이 잠겨 있을 때는 '진짜 전화 화면'(CallKit)이 아니라 알림으로 옵니다.**
> 알림을 눌러 앱에 들어오면 벨이 울리고 받을 수 있습니다.
> 잠금화면에 전화처럼 뜨게 하려면 iOS 네이티브 작업(CallKit + PushKit)이 따로 필요한데,
> 그건 앱 심사 서류도 달라지는 큰 일이라 지금은 넣지 않았습니다.

## 안 될 때

| 증상 | 까닭 · 할 일 |
|---|---|
| 📞 가 아예 안 보인다 | 1:1 대화에서만 보입니다. 사람 이름을 눌러 카드에서 거세요 |
| 학생끼리 📞 가 없다 | 일부러 막았습니다 (1:1 채팅과 같은 규칙) |
| `전화 기능이 아직 설치되지 않았어요` | 1단계를 하세요 |
| 걸면 "마이크를 쓸 수 없어요" | 브라우저 주소창 왼쪽 자물쇠 → 마이크 허용. 아이폰은 설정 → TCS → 마이크 |
| 벨은 울리는데 소리가 없다 | 2·3단계(중계)를 하세요. 학교 와이파이가 대부분 이 경우입니다 |
| 앱을 닫았는데 벨이 안 온다 | 내 프로필에서 알림을 켜야 합니다. 그리고 3단계의 `push-notify` 를 올렸는지 보세요 |
| 들어갈 때마다 옛 벨이 울린다 | 안 그렇게 해 두었습니다 (1분 지난 벨은 무시하고, 묵은 것은 '못 받음'으로 정리) |
