# 💱 필리핀 페소(₱) 추가

DB 설치는 필요 없습니다. `communities.currency` 칸에 `₱` 가 들어갈 뿐입니다.
(`db/공동체통화_DB설치.sql` 을 이미 돌렸다면 그걸로 끝입니다)

**관리 → 공동체 설정 → 💱 통화** 에서 `₱ 페소` 를 고르면 됩니다.

바꿀 때 이미 들어 있는 금액(용돈·예치금·학비)을 **지금 환율로 함께 바꿀지**
물어봅니다. 단위만 바꾸고 숫자는 그대로 두려면 "아니오" 를 누르세요.

환율은 frankfurter.app 에서 받아옵니다. 달러를 기준으로 한 번 받아
통화끼리 나눠서 환산하므로, 원↔페소처럼 달러를 거치는 경우도 맞습니다.
