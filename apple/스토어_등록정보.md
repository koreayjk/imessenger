# 앱 개인정보 보호 (App Privacy)

구글의 '데이터 보안' 과 같은 설문입니다. **답이 서로 달라서는 안 됩니다.**
안드로이드에 적은 것과 맞추세요.

**「사용자에게 연결된 데이터」** 로 두고, **추적(Tracking) 은 하지 않음**:

| 분류 | 항목 | 용도 |
|---|---|---|
| 연락처 정보 | 이름 | 앱 기능 |
| 연락처 정보 | 이메일 주소 | 앱 기능 · 계정 관리 |
| 연락처 정보 | 전화번호 | 앱 기능 (보호자 연락처) |
| 식별자 | 사용자 ID | 앱 기능 |
| 사용자 콘텐츠 | 사진 또는 비디오 | 앱 기능 (증명사진 · 첨부) |
| 사용자 콘텐츠 | 기타 사용자 콘텐츠 | 앱 기능 (채팅 · 노트 · 기록) |
| 금융 정보 | 기타 금융 정보 | 앱 기능 (학비 · 예치금 **기록**) |
| 기타 데이터 | 기타 데이터 | 앱 기능 (생년월일 · 주소 · 학적) |

그리고:

| 질문 | 답 |
|---|---|
| 제3자에게 데이터를 파나요 | **아니요** |
| 광고를 위해 쓰나요 | **아니요** |
| 추적(ATT) 하나요 | **아니요** — 광고 ID 를 쓰지 않습니다 |
| 데이터 삭제를 요청할 수 있나요 | **예** — 앱 안에서 직접 |

> ⚠️ **실제 코드와 일치해야 합니다.** 불일치가 적발되면 앱이 내려갑니다.
